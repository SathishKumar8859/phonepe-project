# 🚀 PhonePe Data Analytics & Visualization Project
### 📊 State-wise • District-wise • Transaction • Insurance • Device Usage Insights

## 📌 Overview
This project visualizes and analyzes PhonePe transaction datasets using Streamlit dashboards, interactive visualizations, and data analytics.

## 🎯 Core Features
- Transaction analytics
- Insurance engagement dashboard
- Device dominance & user engagement
- State-wise & district-wise heatmaps
- Quarterly & yearly trends

## 🏗 Project Architecture
```
phonepe-project
 ┣ data/
 ┣ dashboards/
 ┣ images/
 ┣ dashboard.py
 ┣ requirements.txt
 ┗ README.md
```

## 🖥 How to Run
```
git clone https://github.com/SathishKumar8859/phonepe-project.git
cd phonepe-project
pip install -r requirements.txt
streamlit run dashboard.py
```
